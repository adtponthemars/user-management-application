# User Management Application

A responsive user management dashboard built with **React, TypeScript, and the JSONPlaceholder REST API**.

🔗 **Live Demo:** https://user-management-application-weld-chi.vercel.app/

## Features

* View all users
* Search users
* View detailed user profiles
* Create users
* Edit users
* Delete users with confirmation
* Loading skeletons
* Error handling
* Toast notifications
* Responsive design
* React Router navigation
* TypeScript support

## Tech Stack

* **React**
* **TypeScript**
* **Vite**
* **Tailwind CSS**
* **React Router**
* **JSONPlaceholder API**
* **Lucide React**

## API

This project uses **JSONPlaceholder** to simulate REST API operations.

| Method | Endpoint     | Description         |
| ------ | ------------ | ------------------- |
| GET    | `/users`     | Fetch all users     |
| GET    | `/users/:id` | Fetch a single user |
| POST   | `/users`     | Create a user       |
| PUT    | `/users/:id` | Update a user       |
| DELETE | `/users/:id` | Delete a user       |

> **Note:** JSONPlaceholder simulates POST, PUT, and DELETE operations. Changes are not persisted after refreshing the application.
